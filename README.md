# M5Stack二輪倒立振子：ベイズ最適化とランダムサーチの比較

M5Stack Core2 + Roller485 Lite（2台）で製作した二輪倒立振子のPD制御ゲイン `Kp`, `Kd` を、**ベイズ最適化**と**ランダムサーチ**で探索する実機実験のコードです。

## 実験の概要

- 探索範囲：`Kp = 0～80`, `Kd = 0～4`
- 1セット30試行、各手法3セット（合計180試行）
- 実行順序：ベイズ → ランダム → ランダム → ベイズ → ベイズ → ランダム
- ベイズ最適化：最初の6試行は固定した初期点、その後24試行をガウス過程回帰とExpected Improvementで選択
- ランダムサーチ：30試行すべて独立に一様乱数から選択
- 1試行の制御時間：3秒、RMS評価区間：制御開始1～3秒
- PCとCore2はWi-Fi経由でHTTP通信（`GET /gains`, `POST /result`）

## ファイル

| ファイル | 用途 |
| --- | --- |
| `pc_pd_compare_hotspot.py` | Windows PC側：探索方法の切替、ゲイン決定、HTTPサーバ、CSV保存 |
| `core2_pd_compare_hotspot.py` | Core2側：Wi-Fi通信、自動起立、PD制御、RMS計測 |
| `requirements.txt` | PC側のPython依存パッケージ |

## 使用環境

- Windows PC（Python 3）
- M5Stack Core2 + M5GO Bottom2、Roller485 Lite ×2
- UIFlow2 / MicroPython（M5Stack用ファームウェアとRoller485Unitライブラリが必要）
- PCのモバイルホットスポット等、PCとCore2が通信できるWi-Fi環境

**注意：** Roller485 LiteのI2Cアドレス、モータの取り付け方向、重心位置、起立用バンパーの形状などは実験装置に依存します。ソースコードをそのまま別の機体に適用できるとは限りません。

## 実行方法

1. PCで依存ライブラリをインストールします。

   ```powershell
   py -m pip install -r requirements.txt
   ```

2. `core2_pd_compare_hotspot.py` 冒頭の `SSID` と `PASSWORD` を自分のWi-Fi環境に合わせて設定します。`SERVER` はPCのIPアドレスに合わせて変更します（既定値 `http://192.168.137.1:8000`）。**実際のパスワードを設定したファイルはGitHubにアップロードしないでください。**
3. Core2にプログラムを `main.py` として転送します。
4. PC側で次を実行します。

   ```powershell
   py pc_pd_compare_hotspot.py
   ```

5. Core2を起動し、装置に合わせて水平姿勢でキャリブレーションした後、起立用バンパーにセットして試行します。
6. 結果はPC側に日時入りの `pd_compare_*.csv` として保存されます。

プログラムは**途中停止からの自動再開に対応していません**。停止・再起動時は新しいCSVと新しい180試行が開始されます。

## 結果例（2026年11月の実機実験）

| 指標 | ベイズ最適化 | ランダムサーチ |
| --- | ---: | ---: |
| 試行回数 | 90 | 90 |
| 制御成功 | 72 | 60 |
| RMS ≤ 0.75° | 15 | 3 |
| 成功試行のRMS中央値 | 1.396° | 1.733° |
| 3セットの最小RMS平均 | 0.230° | 0.537° |

この数値は**特定の装置・探索範囲・実験条件で得られた一例**です。3セットずつの結果であり、ベイズ最適化が常に優れることを示すものではありません。最小RMSは同一ゲインの反復測定結果ではなく、各セット内で観測した最良値です。

## 安全上の注意

モータが急回転したり機体が転倒したりする可能性があります。安全な作業領域を確保し、緊急停止できる状態で実験してください。モータ電流上限や転倒判定の値は装置ごとに確認してください。ベイズ最適化は安全な条件だけを探索するアルゴリズムではありません。
